为什么是 MD+

MD+ 是一款为「微信里收到的文档打不开」这个场景而生的阅读器——在微信里点开文件， 点「用其它程序打开」，选 MD+，剩下的交给它。iOS 风格界面、大按钮、单手可用。

功能特性

五种格式

Markdown 完整渲染 / TXT / PDF / EPUB（含插图）/ DOCX 正文

标注

长按选词即可划线（蓝色波浪线）或高亮（黄色色块），自动保存、可筛选跳转

全文搜索

命中高亮、n/m 计数、上下箭头逐条跳转

目录导航

Markdown 标题 / EPUB 章节一键直达

位置记忆

重开文件自动回到上次看到的地方

护眼主题

浅色 / 深色 / 纸白 / 淡暖 / 绿豆沙 / 淡青，可跟随系统切换

隐私与权限

本应用未申请任何 Android 系统权限（包括网络权限），技术上不存在联网与数据上传； 不内置统计、崩溃上报、广告与推送组件。文件访问仅通过系统标准选择器（SAF） 与「用其它程序打开」机制进行。
